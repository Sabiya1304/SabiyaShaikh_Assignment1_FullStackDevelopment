# SabiyaShaikh_Assignment1_CompleteDeveloperPortfolio

A modern, responsive, full-stack personal developer portfolio website developed as **Assignment #1** for the **Full Stack Development Internship at Quillance Infotech Pvt. Ltd.**

## 📌 About the Project

This portfolio showcases my:

* About Me
* Technical Skills
* Education
* Projects
* Internship/Experience
* Certifications
* Resume
* Contact Information

The website includes a functional contact form connected to a backend REST API. Submitted messages are validated and stored in **MongoDB Atlas**.

## 🛠️ Technologies Used

**Frontend**

* HTML5
* CSS3
* JavaScript (ES6+)

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB Atlas
* Mongoose

**Tools**

* VS Code
* Git & GitHub
* npm

```text

                  Validation & Response
```

## 🚀 Run Locally

### Backend

```bash
cd backend
npm install
node server.js
```

Create a `.env` file containing your MongoDB connection string and required environment variables.

### Frontend

Open `frontend/index.html` using **VS Code Live Server** or another local web server.
